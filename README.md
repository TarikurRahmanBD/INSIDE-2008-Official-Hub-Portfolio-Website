# 🌐 INSIDE 2008 — Official Hub & Portfolio Website

**INSIDE 2008** is a sleek, modern, and fully responsive landing page template built to showcase a multi-member team. It serves as a centralized hub to display roles, social links, and creative contributions of any team or group of friends.
